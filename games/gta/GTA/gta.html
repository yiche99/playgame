玩法说明

移动：W前进 / A左移 / D右移 / S后退（相对角色朝向）

视角：移动鼠标转向，点击左键锁定光标

奔跑：Shift

跳跃：空格

攻击：鼠标左键

上车/下车：F

飞机驾驶：F登机 → WASD飞行 → 空格上升 → Shift下降 → F下机

飞机舱门：F（靠近飞机打开/关闭）

进入建筑/离开：F（靠近门）

切换楼层：Q 下楼 / 0 上楼

拾取物品：R（建筑内）

拾取/放下尸体：G

背包：E

切换武器：1-5 / 滚轮

放大地图：点击右上角小地图

暂停：ESC

捣乱越大 → 通缉越高 → 奖励越多！
